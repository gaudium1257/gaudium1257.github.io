# TH 아이콘

사이트 아이콘(TH 블록 모노그램, 2026-11 소유자 선택 E안)을 따로 쓰기 위한 사본입니다. 프로필 사진, 발표 자료 등에 씁니다. 사이트에는 배포되지 않습니다.

| 파일               | 내용                                            |
| ------------------ | ----------------------------------------------- |
| `th-icon.svg`      | 원본 벡터 (`src/app/icon.svg`와 같음)           |
| `th-icon-1024.png` | 1024×1024 PNG, 둥근 모서리, 바깥 투명           |
| `th-icon-512.png`  | 512×512 PNG                                     |
| `th-icon-256.png`  | 256×256 PNG                                     |
| `favicon.ico`      | 사이트 탭 아이콘 (`src/app/favicon.ico`와 같음) |

원본은 `src/app/icon.svg`(사이트 아이콘)와 `public/brand/th-mark.svg`(머리글 마크)입니다. 아이콘을 바꾸면 이 폴더도 다시 만듭니다.
