# EP-0008: 가독성·색·홈 구성 손보기

- **상태**: DONE
- **시작**: 2026-09-09
- **관련**: [DESIGN.md](../../DESIGN.md) · [viewer-site 스펙](../../product-specs/viewer-site.md) · [EP-0006](../completed/0006-docs-skin.md)

## 목표

배치를 바꾸는 동안 **활자 크기와 색을 손보지 않았다.** 그 결과:

1. 본문이 14px, 메타가 12px 다 — 훑는 화면이 아니라 읽는 화면인데 작다
   (`text-sm` 24곳, `text-xs` 11곳, `text-base` 4곳)
2. 브랜드색이 링크·번호에만 쓰인다. 화면이 회색 일변도로 읽힌다
3. `.hero-surface` 그라데이션이 CSS 에 남아 있는데 **아무도 쓰지 않는다** —
   좌측 목차로 바꾸며 클래스를 떼어냈다. 사용자가 "예전엔 그라데이션 있었잖아" 라고 한 게 이것이다
4. 홈에서 소개를 볼 수 없다. About 에 자기소개를 넣었는데 홈이 그걸 안 보여준다

## 완료 조건 (Acceptance)

- [x] 본문 기본 크기가 16px 다. 메타는 13~14px 로 올린다
- [x] 활자 크기가 **정해진 계단**을 따른다 — 화면마다 다른 크기를 쓰지 않는다
- [x] 브랜드색이 강조에 쓰인다 (활성 목차·태그·괘선 등). 남발하지 않는다
- [x] 표면 그라데이션이 **다시 보인다** — 새 배치에 맞는 자리에
- [x] 홈에 자기소개 일부가 보이고 About 으로 이어진다
- [x] 라이트·다크 양쪽에서 대비가 유지된다
- [x] `npm run verify` 통과
- [x] 관련 문서 갱신 (INV-10)
