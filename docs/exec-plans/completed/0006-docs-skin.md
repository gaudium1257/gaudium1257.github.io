## 목표

시안 07(문서 도구)을 **두 앱 모두에** 적용한다.

> **방향 변경 (2026-09-09, 작업 중)**
> 처음 요청은 "admin 에만 먼저" 였고, 그래서 `skin` 선택지를 두려 했다.
> 작업 중 사용자가 **"그냥 두개다 바꿔"**, **"레이아웃 선택가능하게 하지마"** 로 바꿨다.
> 선택지를 걷어내고 배치 한 가지로 간다 — 결과적으로 코드가 훨씬 단순해졌다.

관찰 가능한 결과:
1. viewer·admin 이 좌측 목차 + 문서형 본문으로 보인다
2. 폰트·색은 기존 토큰 그대로다. 바뀌는 것은 배치뿐이다

## 두 앱이 표시 레이어를 공유한다

`shared/portfolio` 한 곳을 고치면 두 앱이 함께 바뀐다 (ADR-0005).
이번엔 그게 정확히 원하는 결과라 **추가 장치가 필요 없었다.**
