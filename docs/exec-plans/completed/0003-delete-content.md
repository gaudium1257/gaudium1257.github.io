# EP-0003: 콘텐츠 삭제 기능

- **상태**: DONE
- **시작**: 2026-09-08
- **관련**: [ADR-0003](../../design-docs/adr/0003-content-store.md) · [admin-editor 스펙](../../product-specs/admin-editor.md) · [ADR-0005](../../design-docs/adr/0005-shared-presentation.md)

## 목표

admin 에서 **항목을 지우고 게시할 수 있다.** 터미널을 열지 않는다.

지금 `DELETE /api/content` 는 구현·테스트까지 되어 있으나 **부르는 화면이 없다.**
그래서 샘플 콘텐츠를 지우려면 파일 탐색기나 터미널을 써야 한다.

관찰 가능한 결과:
1. 편집 패널에서 삭제를 누르면 확인을 거쳐 항목이 사라진다
2. 게시 모달에 `[삭제] 고려대학교 컴퓨터학과` 처럼 **제목**이 뜬다 (id 나 파일명이 아니라)
3. 게시하면 공개 사이트에서도 사라진다

## 완료 조건 (Acceptance)

- [x] 편집 패널에 삭제 버튼이 있고, 확인 없이는 지워지지 않는다
- [x] **프로필은 삭제할 수 없다** — 하나뿐이고 없으면 Hero·About 가 깨진다
- [x] 새 항목(저장 전)에는 삭제 버튼이 뜨지 않는다
- [x] 게시 모달이 삭제된 항목을 **제목**으로 보여준다
- [x] viewer 번들에 삭제 코드가 들어가지 않는다 (INV-8)
- [x] `npm run verify` 통과
- [x] 관련 문서 갱신 (INV-10) — admin-editor 스펙에 삭제 흐름

## 범위 밖

- **되돌리기(undo)** — git 이력에 남으므로 `git revert` 로 복구한다. 화면에 넣지 않는다
- **여러 항목 일괄 삭제** — 지금 콘텐츠 규모에서 필요 없다
- **목록 카드에 삭제 버튼 노출** — 파괴적 버튼을 모든 카드에 두면 오클릭이 난다. 편집 패널 안에만 둔다
- `shared/portfolio` 의 편집 슬롯 계약 변경 — `renderItemAction` 이 노드를 반환하므로 admin 쪽에서 조합하면 된다
- viewer 변경 없음
