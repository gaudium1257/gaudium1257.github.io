## 목표

세 가지를 고친다 (2026-09-09 사용자 요청):

1. **번호(01·02·03)를 전부 없앤다.** 목차·섹션·목록 어디에도 쓰지 않는다
2. **홈의 실적 숫자를 없앤다** (논문 리뷰 1 · 글 3)
3. **넓은 화면에서 모바일 레이아웃처럼 보이지 않게 한다**

## 무엇이 문제인가 — 3번

지금 본문은 어떤 화면에서든 `max-w-3xl`(768px) 한 칼럼이다.
1920px 모니터에서 **오른쪽 절반이 빈다.** 폭이 안 늘어나니 휴대폰 화면을 늘려놓은 것처럼 읽힌다.

그렇다고 본문을 무작정 넓히면 안 된다 — 글 줄이 길어지면 눈이 줄을 놓친다.
**읽는 것과 훑는 것을 나눈다:**

- 글(마크다운 본문·소개)은 읽기 좋은 폭으로 **묶어 둔다**
- 목록·홈은 넓은 화면에서 **폭을 쓰고**, 날짜·메타를 옆 열로 빼 표처럼 정렬한다
