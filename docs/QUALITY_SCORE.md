## 등급 기준

| 등급 | 의미 |
|---|---|
| **A** | 테스트로 덮여 있고, 문서가 최신이며, 불변식 위반 0 |
| **B** | 동작하고 불변식은 지키지만 테스트나 문서에 구멍이 있음 |
| **C** | 동작하지만 패턴이 어긋남. 근처를 건드릴 때 함께 고친다 |
| **D** | 불변식을 우회 중. tech-debt-tracker 에 P0/P1 로 등록되어 있어야 함 |
| **–** | 아직 없음 |
