# ADR-0004: 내비게이션 셸 — 검색과 테마

- **상태**: ACCEPTED
- **날짜**: 2026-09-06
- **관련**: [navigation-shell.md](../../product-specs/navigation-shell.md), [DESIGN.md](../../DESIGN.md)

## 맥락

viewer 상단에 고정 배너가 있다. 좌상단 사이트 이름, 가운데 섹션 탭 5개
(`Home · About · Paper Review · Project · Blog`), 우상단 도구 2개(검색 · 테마).

> **다국어는 만들지 않는다** (사용자 결정, 2026-09-06).
> 초기 구상에 있던 Language 버튼은 제거했다. 콘텐츠 스키마에 언어별 필드를 두지 않으므로
> **나중에 도입하려면 스키마 마이그레이션이 필요하다** — 그때 새 ADR 을 쓴다.

두 도구는 성격이 다르다. 하나로 뭉뚱그리면 나중에 각각 다른 이유로 깨진다.

## 검토한 선택지

**검색**
| 선택지 | 장점 | 단점 |
|---|---|---|
| **빌드 타임 인덱스 + 클라이언트 검색 (채택)** | 서버 불필요, 즉시 응답 | 콘텐츠가 아주 많아지면 번들 증가 |
| 외부 검색 서비스 | 확장성 | 계정·키·요금. 개인 포트폴리오에 과함 (CB-7) |

**테마**
| 선택지 | 장점 | 단점 |
|---|---|---|
| **명시적 토글 + 시스템 기본값 (채택)** | 사용자가 고를 수 있고 첫 방문은 시스템을 따름 | 저장소 접근이 막히면 기억 못 함 |
| 시스템 설정만 따름 | 구현 최소 | 사용자가 바꿀 수 없음 (요구사항 위반) |

## 결정

두 가지를 **각각 독립 프로바이더**로 만든다. 서로를 모른다.

1. **검색** — 빌드 타임에 콘텐츠에서 인덱스를 만들고 클라이언트에서 조회한다.
   검색어는 **URL 쿼리에 둔다** (`?q=...`) — 공유·새로고침·뒤로가기가 동작해야 한다 (GR-5)
2. **테마** — `light | dark | system` 세 상태. 기본은 `system`.
   선택은 `localStorage` 에 남기고, 색은 **토큰 레벨에서만** 바꾼다 (컴포넌트에 분기 금지)

**셸은 `viewer/src/app/` 에서 조립한다.** 도메인은 자기가 어느 탭 아래 있는지 모른다 (INV-1).

## 결과

- 좋아지는 것: 둘 중 하나가 바뀌어도 나머지가 영향받지 않는다.
  검색 결과가 URL 로 표현되어 링크로 공유된다
- 나빠지는 것: 테마 토큰이 하드코딩된 색을 만나면 다크 모드가 깨진다
  → `lint:arch` 가 매직 색상값을 잡는다
- 다국어를 포기한 대가: 영문 지원이 필요해지면 스키마부터 다시 봐야 한다

## 되돌리는 조건

- 콘텐츠가 수백 건을 넘어 검색 인덱스가 무거워지면 → 지연 로딩 또는 외부 검색 ADR
- 영문 포트폴리오가 필요해지면 → 다국어 도입 ADR (스키마 마이그레이션 포함)
