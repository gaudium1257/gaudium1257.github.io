# `/design` 프롬프트

`/design` 명령에 붙여넣는 포트폴리오 사이트 디자인 요청입니다. 예시 데이터(홍길동, 프로젝트 이름 등)는 화면을 채우기 위한 가짜 내용입니다.

```text
개인 포트폴리오 웹사이트를 디자인해줘.

[주인공]
AI·웹 프로젝트를 만드는 한국 대학생 개발자. AI 교육, 바이브코딩 교육, 해커톤을 운영하는 학회에서 활동한다.

[보는 사람]
채용 담당자, 해커톤 심사위원, 협업할 사람. 짧게 훑어보고 원하는 정보(특정 프로젝트, 수상, 연락처)로 바로 이동하고 싶어한다.

[섹션]
소개, 프로젝트, 대외활동, 수상, 학회, 개발 역량, 학력, 연락처(GitHub, 이메일, 인스타그램, 디스코드), 하단에 "© 2026 홍길동".

[꼭 지킬 것]
- 내비게이션(섹션 목차)과 KO/EN 언어 전환은 화면 위쪽에 붙어 있게. 스크롤해도 따라오고 현재 위치가 표시되면 좋다.
- 어떤 섹션이든 한 번 클릭으로 이동. 긴 스크롤은 피하고, 항목이 많은 섹션은 요약만 보여준 뒤 '전체 보기'나 상세 페이지로.
- 큰 구조는 한 페이지 스크롤이든 페이지 이동이든 자유롭게 정해도 된다.
- 프로젝트·대외활동·수상·학회 활동은 서로 겹치는 경우가 많으니(예: 해커톤 프로젝트가 수상으로 이어짐) 관련 항목끼리 연결되어 보이게.
- 가독성 최우선. 한글과 영어가 모두 잘 읽히는 글꼴과 줄 간격.
- 브랜드 색은 보라색.
- 반응형. 모바일(375px)에서도 위쪽 내비가 자연스럽게 동작하고 가로 스크롤이 없게.
- 프로젝트 상세 화면도 함께: 요약, 핵심 기능, 내가 한 일, 기술 스택, 현재 상태(배포 위치), 결과, 문제와 해결, 링크, 관련 항목.

[구현 참고]
Next.js + Tailwind CSS로 옮길 예정이라 색·글꼴·간격은 CSS 변수(디자인 토큰)로 정리해줘. 한국어와 영어 문구 길이가 달라도 깨지지 않게.

[예시 데이터 — 가짜]
홍길동, "AI와 웹으로 문제를 푸는 개발자". 프로젝트: 스터디 타이머(팀·해커톤, Next.js·Supabase), 강의 요약 챗봇(개인, FastAPI·OpenAI API), 학회 출석 관리 서비스(학회, React·Firebase). 수상: OO 해커톤 대상. 학회 행사: 바이브코딩 입문 교육, 교내 AI 해커톤 운영.
```
