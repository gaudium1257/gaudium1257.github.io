# 참고 자료 색인

외부 문서를 **에이전트가 읽을 수 있는 형태로** 저장소 안에 둔다.
저장소 밖 지식은 존재하지 않기 때문이다 (CB-1).

| 파일 | 대상 | 갱신 방법 |
|---|---|---|
| _(아직 없음)_ | | |

## 무엇을 여기에 두는가

- 자주 참조하는 라이브러리의 요약본 (`*-llms.txt`)
- 버전에 민감해서 기억에 의존하면 틀리는 API
- 웹 검색으로 매번 찾게 되는 것

## 무엇을 두지 않는가

- 라이브러리 문서 전체 복사본 (컨텍스트 낭비)
- 곧 바뀔 것 (대신 확인 방법을 적는다)

## 규칙

- 파일 상단에 **출처 URL 과 확인 날짜**를 반드시 남긴다 (`확인: YYYY-MM-DD`)
- 원문의 저작권을 존중한다. 전문 복제가 아니라 **필요한 요약**을 둔다
- 6개월 이상 확인 날짜가 갱신되지 않으면 `/doc-gardening` 이 검토 대상으로 올린다
