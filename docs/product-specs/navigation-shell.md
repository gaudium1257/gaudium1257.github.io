# 스펙: 내비게이션 셸

- **상태**: AGREED
- **관련**: [ADR-0004](../design-docs/adr/0004-navigation-shell.md), [DESIGN.md](../DESIGN.md)

모든 페이지를 감싸는 **좌측 목차**. 사이트의 뼈대이므로 여기가 흔들리면 전부 흔들린다.

## 배치 (2026-09-09 변경 — 상단 배너에서 좌측 목차로)

```
┌──────────────┬─────────────────────────────────────────────┐
│ 김태호        │                                             │
│ 🏠 홈         │   📓                                        │
│ 👤 소개       │   김태호                                    │
│ 📄 논문 리뷰  │   문제를 정의하고 …                          │
│ 🛠️ 프로젝트   │                                             │
│ ✏️ 블로그     │   📄 논문 리뷰            전체 보기 →        │
│              │   ──────────────────────────────────        │
│ 🔍  ☀/🌙      │   📄 Attention Is All You Need              │
└──────────────┴─────────────────────────────────────────────┘
```

- **좌측 상단**: 사이트 이름 `김태호`. 클릭하면 홈으로 간다.
  **설정값 하나로 바꿀 수 있어야 한다** (사용자가 나중에 바꾼다고 명시함)
- **좌측 목차**: 섹션 5개 — `홈` · `소개` · `논문 리뷰` · `프로젝트` · `블로그`
- **좌측 하단**: 도구 2개 — 검색 · 테마

왜 세로인가: 탭이 세로로 서면 항목을 늘려도 줄이 밀리지 않고, 본문 폭이 좁아져
글이 읽기 좋은 길이로 떨어진다. 시안 07(문서 도구)에서 온 형태다 → [EP-0006](../exec-plans/completed/0006-docs-skin.md)

**좁은 화면(md 미만)에서는 가로로 눕는다.** 224px 짜리 열을 모바일에 그대로 두면
본문이 설 자리가 없다 — 세로 목차는 넓은 화면의 사치다.

> **다국어(Language)는 만들지 않는다** — 사용자 결정 (2026-09-06).
> → [ADR-0004](../design-docs/adr/0004-navigation-shell.md)

## 동작

| # | 동작 | 기대 결과 |
|---|---|---|
| N-1 | 탭 클릭 | 해당 섹션으로 이동. **현재 위치한 탭이 시각적으로 표시**된다 |
| N-2 | 사이트 이름 클릭 | Home 으로 이동 |
| N-3 | 딥링크 진입 / 새로고침 | 해당 페이지가 뜨고 올바른 탭이 활성 표시된다 |
| N-4 | 모바일 | 목차가 **가로로 눕고** 스크롤된다. 페이지에 가로 스크롤이 생기지 않는다 |
| N-5 | 키보드 | Tab 으로 모든 항목에 도달하고 Enter 로 활성화된다 (GR-7) |

### 검색

| # | 동작 | 기대 결과 |
|---|---|---|
| S-1 | 검색 버튼 클릭 | 검색 입력이 열리고 **포커스가 입력으로 이동**한다 |
| S-2 | 검색어 입력 | 논문 리뷰·프로젝트·블로그 글을 가로질러 결과가 나온다 |
| S-3 | 결과 클릭 | 해당 항목으로 이동한다 |
| S-4 | 검색어가 URL 에 반영 | `?q=...` 로 남아 **공유·새로고침·뒤로가기가 동작**한다 (GR-5) |
| S-5 | 결과 없음 | "결과 없음"을 분명히 알린다. 빈 화면으로 두지 않는다 |
| S-6 | Esc | 검색을 닫는다 |

### 테마

| # | 동작 | 기대 결과 |
|---|---|---|
| T-1 | 첫 방문 | 시스템 설정(`prefers-color-scheme`)을 따른다 |
| T-2 | 토글 | bright ↔ dark 가 즉시 바뀐다 |
| T-3 | 선택 유지 | 재방문 시 기억한다 |
| T-4 | 저장소 접근 불가 | 기억은 못 해도 **화면은 정상 동작**한다 (프라이빗 모드 등) |
| T-5 | 두 테마 모두 | 대비 기준을 만족한다. 하드코딩된 색이 없어야 가능하다 (DESIGN.md) |

## 하지 않는 것

- **다국어** (결정: 만들지 않음)
- 검색 자동완성·오타 교정 (콘텐츠 규모에 비해 과함)
- 사용자 계정·개인화
- 배너에 항목 추가 — 5개 탭 + 2개 도구가 상한이다. 늘리려면 스펙을 먼저 고친다

## 탭 이름은 한국어다 (2026-09-08 결정)

`홈 · 소개 · 논문 리뷰 · 프로젝트 · 블로그`.

**경로(URL)는 영어 그대로 둔다** (`/papers`, `/projects`, `/blog`).
이미 나간 링크가 깨지고, 프리렌더 경로도 여기서 나온다. 바뀌는 건 보이는 이름뿐이다.

이름의 유일한 출처는 `shared/portfolio/config` 의 `SECTION_LABELS` 다.
배너 탭도 페이지 제목도 여기서 읽는다 — 두 곳에 적어두면 배너는 '논문 리뷰' 인데
페이지 제목은 'Paper Review' 로 갈라진다.

`SECTION_LABELS` 는 `{ ko, en }` 쌍을 들고 있고 `sectionLabel()` 이 지금은 `ko` 만 고른다.
**언어 전환을 나중에 넣기로 했으므로**, 그때 이 함수만 바뀐다.
