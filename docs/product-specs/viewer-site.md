## 성공 기준

심사자가 **30초 안에** "이 사람이 무엇을 할 수 있는가"를 파악한다.

## 페이지 5개

### Home — 요약 화면

다른 네 섹션을 **압축해서** 보여준다. 전체를 나열하지 않는다.
**각 섹션 3개씩** 보여준다 (기본안 채택, 2026-09-06).

| # | 동작 | 기대 결과 |
|---|---|---|
| H-1 | 진입 | 이름·한 줄 소개가 스크롤 없이 보인다 |
| H-2 | About 요약 | 짧은 소개가 보이고 About 전체로 가는 링크가 있다 |
| H-3 | Paper Review 3개 | 최근 3건 + 전체 목록 링크 |
| H-4 | Project 3개 | 대표 3건 + 전체 목록 링크 |
| H-5 | Blog 3개 | 최근 3건 + 전체 목록 링크 |
| H-6 | 비어 있는 섹션 | 섹션 자체를 숨긴다. 빈 제목만 남기지 않는다 |

### About — 소개와 스펙

| # | 동작 | 기대 결과 |

| A-1b | 자기소개가 비면 | viewer 는 그 자리를 **숨긴다**. admin 에만 어디에 쓰는지 안내가 뜬다 |
