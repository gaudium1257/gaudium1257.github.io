- [ ] 다국어(한/영)가 필요한가?

## 동작 (가설)

| # | 동작 | 기대 결과 |
|---|---|---|
| P-1 | 첫 화면 진입 | 이름·한 줄 소개·핵심 역량이 스크롤 없이 보인다 |
| P-2 | 프로젝트 목록 열람 | 각 항목의 역할과 결과를 목록에서 판단할 수 있다 |
| P-3 | 프로젝트 상세 열람 | 문제 → 접근 → 결과 순서로 읽힌다 |
| P-4 | 글/리뷰 열람 | 작성일 순으로 훑고 개별 글을 읽을 수 있다 |
| P-5 | 모바일 접속 | 모든 정보가 가로 스크롤 없이 읽힌다 |
| P-6 | 인쇄/PDF 저장 | 레이아웃이 무너지지 않는다 |
| P-7 | 콘텐츠 없음 | 빈 섹션이 흉하게 남지 않는다 (섹션 자체를 숨긴다) |
| P-8 | 딥링크 진입/새로고침 | 404 가 나지 않는다 (GitHub Pages SPA 라우팅 처리) |
