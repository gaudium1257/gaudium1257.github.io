# 디자인 시안 — "이력서 판형 (Résumé Sheet)"

구현의 기준이 되는 디자인입니다. 시안 캔버스: <https://claude.ai/artifact/95ysTmLFNbQUmphosPmcRx> (홈·상세·목록 × 한국어/English × 1440/390, 12개 아트보드).
시안 HTML은 [`mockup/gen.py`](mockup/gen.py) 하나에서 생성됩니다. 디자인을 바꿀 때는 이 생성기를 고치고 다시 렌더링·검증한 뒤 캔버스에 올립니다.

## 콘셉트

한국식 이력서를 웹 페이지로 옮긴 형태. 첫 화면 왼쪽에 3:4 증명사진, 그 옆에 이름과 검증 가능한 사실 목록. 아래 모든 섹션은 사진과 같은 세로축(라벨 열 216px + 내용 열)에 걸리고, 카드·칩·배지 대신 얇은 가로줄(hairline)로 구분된 행으로 구성합니다. 보라색은 링크, 현재 위치 표시, 현재 직책 점, "내가 한 일" 세로줄에만 씁니다.

## 레이아웃 규칙

- **헤더(고정)**: 데스크톱 64px 한 줄 — 이름(라벨 열) · 섹션 탭(내용 열 시작선에 글자 정렬) · KO/EN. 모바일 48px — 섹션 탭 가로 스크롤(오른쪽 32px 페이드) · KO/EN. 활성 탭은 ink 600 + 2px 보라 바(헤더 하단선 위에 겹침). 1199px 이하에서는 이름 칸이 136px로 줄고 탭 패딩이 8px로 줄어 영어 8개 탭이 1024px에서도 모두 보입니다(두 줄 헤더의 탭 시작선도 서로 맞음).
- **상세 페이지 헤더**: 1행은 사이트 섹션 탭(프로젝트 활성), 2행(44px)은 페이지 목차(요약·내가 한 일·핵심 기능·기술 스택·결과·문제와 해결·관련 항목). 모바일도 동일한 2행.
- **섹션 껍데기**: 위쪽 가로줄 1개 + 패딩 40px(모바일 24/32). 섹션 끝에 닫는 줄을 따로 긋지 않습니다(다음 섹션의 위쪽 줄이 닫음). 각 목록의 첫 행은 위쪽 줄 없음, 마지막 행은 아래 패딩 0.
- **행(ledger row)**: `날짜 136px | 내용`. DOM 순서는 제목 먼저, 날짜는 CSS `order: -1`로 앞에 표시(스크린리더가 제목부터 읽도록).
- **관계 표시**: "관련" 라벨 + 보라 밑줄 링크. 데스크톱은 `·` 구분. 모바일은 라벨 옆에 별도 줄바꿈 상자를 두고 44px 높이 링크를 나열(구분자 없음, 줄이 바뀌어도 첫 링크 아래로 정렬). 스크린리더용 접두어는 짧게("수상: ", "프로젝트: "), 화면에 이미 종류 라벨이 있으면 생략.
- **프로젝트 상태**: 한 자리에 한 형식으로. 목록 행의 슬롯은 항상 **배포 상태**(`유형 · 배포 상태`, 배포 중이면 초록 점 + "배포 중"). 진행 상태(완료/진행 중)는 상세 페이지의 별도 칸에만.
- **목록 행 구조**: `날짜 | [제목·소개·관련 | 유형·상태·스택]` — 제목과 메타를 한 묶음으로 감싸, 좁은 폭(768–1199px)에서는 메타가 제목 아래로 내려가고 날짜 열 아래로 떨어지지 않게. 행 전체가 하나의 링크(stretched link), 화살표는 오른쪽 끝에 고정.

## 페이지 구성

- **홈**: 소개(사진 216×288 / 모바일 104×139 · 이름 · 역할 3개 · 소개 · 사실 목록) → 프로젝트(대표 1개 + 목록 행, "전체 보기"→목록 페이지) → 대외활동 → 수상 → 학회(소개 · 직책 타임라인 · 운영한 행사) → 개발 역량(카테고리별, 기술 → 사용한 프로젝트 링크) → 학력 → 연락처(GitHub · 이메일+복사 · Instagram · Discord+복사).
- **프로젝트 상세**: ← 프로젝트 목록 · 유형/수상 · 제목 · 한 줄 소개 · 데모/GitHub/발표 자료 · 사실 4칸(기간 · 팀·내 역할 · 진행 상태 · 배포) → 요약 → 내가 한 일 → 핵심 기능(스크린샷 + 기능 행) → 기술 스택 → 결과 → 문제와 해결 → 관련 항목 → 이전/다음 프로젝트. 푸터에 이메일·GitHub.
- **프로젝트 전체 목록**: ← 홈 · 제목 · 개수 · 모든 프로젝트 행. 필터는 프로젝트가 6개 이상일 때만.

## 구현 시 지켜야 할 동작 (시안에서 정적으로 보여줄 수 없는 것)

1. **홈 노출 개수**: 프로젝트 대표 1 + 행 2, 대외활동·수상·학회 행사 최근 3개. 전체가 노출 개수보다 많을 때만 "전체 보기"를 렌더링.
2. **스크롤 스파이**: 현재 섹션 = 화면 높이 45% 지점 위에 top이 있는 마지막 섹션. 페이지 끝에 닿으면 마지막 섹션을 활성화(학력·연락처도 표시되도록). 탭 클릭 시 즉시 `aria-current` 변경, 스크롤이 끝날 때까지 관찰 무시.
3. **탭 가시성**: 활성/포커스 탭이 바뀌면 `scrollIntoView({ inline: "nearest", block: "nearest" })` (시안에는 `focusin` 핸들러로 구현). `header nav { scroll-padding-inline-end: 40px }`로 페이드 아래에 숨지 않게.
4. **굵기 변화로 인한 흔들림 방지**: 탭 라벨에 `data-label` + `::after`(600, visibility hidden)로 굵은 폭을 미리 확보.
5. **복사 버튼**: 시각 32px + `::after`로 44px 터치 영역. 복사 후 `role="status"` 영역에 "복사했어요"/"Copied".
6. **언어**: `/ko/…` ↔ `/en/…` 같은 페이지로 전환. 영어 페이지의 H1·헤더·푸터·`<title>`은 영어 이름(`profile.name.en`), 한글 이름은 보조로 `lang="ko"`. 한국어 페이지의 영어 이름 보조에는 `lang="en"`.
7. **이미지**: 사진·썸네일·스크린샷이 없으면 해당 자리를 렌더링하지 않음(시안의 회색 자리는 위치 표시용).
8. **링크**: 외부 링크는 `target="_blank" rel="noopener noreferrer"` + 스크린리더용 "(새 탭)".
