# 디자인 시안 — "움직이는 포스터 (Moving Poster)"

구현의 기준이 되는 디자인입니다. 시안 캔버스: <https://claude.ai/artifact/95ysTmLFNbQUmphosPmcRx> (홈·상세·목록 × 한국어/English × 1440/390, 12개 아트보드, 모두 인터랙티브).
시안은 [`mockup/sys/gen.py`](mockup/sys/gen.py) 하나에서 생성됩니다. 같은 마크업이 ① Tailwind로 컴파일한 정적 페이지 6개(`mockup/proto/sys-*`)와 ② 캔버스 아트보드 12개가 됩니다. 디자인을 바꿀 때는 생성기를 고치고, 다시 렌더링·검증한 뒤 캔버스에 올립니다(맨 아래 "시안 다시 만들기").

시안의 클래스 문자열이 그대로 실제 컴포넌트의 클래스가 됩니다. 시안과 사이트가 같은 Tailwind 토큰과 유틸리티를 씁니다.

## 콘셉트

흰 바탕 위의 평면 바우하우스 포스터. 모든 것이 정사각형 모듈 위에 놓입니다.

- **도형이 구조다.** 도형은 격자 칸(포스터 모듈, 커버 패널, 모듈 열, 썸네일)을 차지합니다. 텍스트는 절대 도형 위에 올리지 않습니다.
- **도형이 뜻을 가진다.** 전역 **도형 범례(Shape Key)** 하나가 일의 종류를 표시하고, 섹션마다 **종류 표식(kind mark)** 이 있습니다. 프로젝트 커버는 그 프로젝트가 하는 일(타이머·QR·챗봇…)에서, 썸네일은 활동 유형에서, 기술 도형은 기술 분류에서 나옵니다.
- **움직임은 릴레이다.** 한 섹션 안에서는 한 번에 도형 하나만, 1.2–2.4초 동안 한 걸음 움직이고 멈춥니다. 각 도형은 24초에 한 번 움직입니다. 몇 초마다 한 조각씩 바뀌는 포스터처럼 보입니다.
- **날짜는 그냥 글자.** 항상 `yyyy.mm`, `tabular-nums`. 날짜로 위치·크기·도형을 만들지 않습니다.

모서리는 전부 직각. 색은 잉크·보라·보라 틴트·흰색뿐입니다. 그라데이션·그림자·블러·이모지 없음.

## 도형 어휘

모든 도형은 Tailwind만으로 만듭니다(SVG 없음). 도형은 `relative overflow-hidden` 모듈 안에 % 단위로 배치해서 80px~560px 어디서든 같은 구성이 됩니다.

| 도형      | 레시피                                                       |
| --------- | ------------------------------------------------------------ |
| 사각형    | `div` + `bg-*`                                               |
| 원        | `rounded-full`                                               |
| 사분원    | `rounded-tl-full` (tr/br/bl)                                 |
| 반원·아치 | `aspect-[2/1] rounded-t-full` (매달린 반원 `rounded-b-full`) |
| 삼각형    | `tri` · 모서리 삼각형 `tri-corner`                           |
| 마름모    | 사각형 + `rotate-45`                                         |
| 말풍선    | `rounded-full rounded-bl-none`                               |
| 반반 원   | `rounded-full overflow-hidden` + 왼쪽 절반 `bg-ink`          |
| 메달      | 원 + 가운데 흰 원                                            |

한 구성 안의 비율은 대략 잉크 25% · 보라 30% · 틴트와 흰색 45%. 이웃한 모듈은 배경색이 겹치지 않게 합니다.

## 움직임

1. **모든** 애니메이션과 transform 전환은 `motion-safe:` 뒤에. 색·테두리 전환만 예외.
2. **움직임 줄이기 = 설계된 정지 구성.** 모든 키프레임의 0% 자세가 곧 정지 화면이고, 스크린샷도 그 상태입니다. 이때 멈춤 버튼은 숨깁니다.
3. 헤더의 멈춤 버튼(`aria-pressed`, 라벨이 바뀜, `localStorage` 키 `motion`)이 루트에 `data-motion="off"`를 걸면 `--play: paused`가 상속되어 모든 루프가 멈춥니다(WCAG 2.2.2). 화면 밖 루프는 `play-gate` 컨테이너 안에 있고, IntersectionObserver 하나가 `data-inview="true"`를 걸어 줄 때만 돕니다.
4. **릴레이 규칙**: 한 섹션의 루프는 24초 주기를 나눠 씁니다. 히어로 포스터는 3·9·15·21초에 한 걸음씩(사분원 90° 회전 → 사각형이 마름모로 → 아치 속 해가 떠오름 → 잉크 막대의 반원이 미끄러짐). 동시에 둘이 움직이지 않습니다(검증 스크립트가 100ms 간격으로 확인).
5. 연속 루프는 시계 쐐기 하나(60초/바퀴)뿐. 나머지 루프 주기는 24·48·96초뿐.
6. 키프레임은 `transform`/`opacity`만. hover는 Tailwind의 `translate`/`rotate`/`scale` 속성을 쓰므로 루프와 겹치지 않습니다. 같은 요소·같은 속성에 hover와 루프를 같이 두지 않습니다.

| 루프           | 움직임                      | 주기 | 쓰는 곳 (오프셋)                                                       |
| -------------- | --------------------------- | ---- | ---------------------------------------------------------------------- |
| `quarter-step` | 1.2초에 90° 회전 후 정지    | 96s  | 히어로 사분원(93), 푸터 플린스(93), 연락처 모듈(81)                    |
| `diamond-step` | 사각형 ↔ 마름모             | 48s  | 히어로 사각형(39), 개발 역량 사각형(45), THE LAB 교육 모듈, 플린스(39) |
| `sun-step`     | 아치 속 원이 떠올랐다 짐    | 48s  | 히어로 해(33), THE LAB 세미나 모듈(33)                                 |
| `slide-step`   | 반원이 옆 칸으로 미끄러짐   | 48s  | 히어로 잉크 막대(27)                                                   |
| `hop`          | 18% 위로 뛰었다 내려옴      | 24s  | 시계 커버의 원 셋(22/14/6), AI 삼각형(5)                               |

- 오프셋은 "로드 순간의 자세 = 정지 자세"가 되도록 골랐습니다. 새 루프를 넣을 때도 이 조건을 지킵니다.
- **등장**: 히어로 포스터 모듈이 사진에서 가까운 순서로 `pop`(0.8초, 0→1배, 0–400ms 지연). 히어로 텍스트는 범례 → 이름 → 소개 → 사실 → 버튼 순으로 `enter`(0.9초, 14px 떠오름). 상세 커버도 `pop`. 섹션 표식은 스크롤 연동 `reveal`.
- **hover/focus** (500–700ms, `ease-snap`, 모두 motion-safe): 포스터 도형이 한 칸씩 비켜남 · 커버 도형 이동/회전 · 썸네일 도형 4–8px · 학회 행사 타일에 올리면 THE LAB의 같은 종류 모듈에 흰 링(움직임 줄이기에서도 보임) + 그 도형이 움직임 · 내비 현재 막대 `scale-x` · 버튼 원은 작아지고 사각형은 마름모로 · 카드는 `hover:border-ink`(색 변화라 항상).

## 레이아웃과 반응형

- 섹션 래퍼: `scroll-mt-32 md:scroll-mt-24 lg:scroll-mt-20` + `border-t border-line`, 안쪽 `shell py-8 sm:py-10 lg:py-12`. 학회만 `bg-surface`, 위 테두리 없음.
- **헤더**(sticky): 640 미만 = 44px 줄 + 4×2 격자(36px 행) = 118px, 8개 섹션이 모두 한눈에. 768–1023 = 44px + 한 줄 8칸(44px) = 89px. 1024 이상 = 64px 한 줄, 현재 섹션 아래 4px 보라 막대. 세로 500px 이하 화면은 가로 스크롤 띠. 하단 hairline은 `after:`로 그려서 높이에 포함.
- **히어로**: 1024 이상 12열 — 왼쪽 6열 = 범례 + 이름, 오른쪽 6열 = 5×5 포스터(최대 560px), 소개·사실·버튼은 포스터 아래 끝에 맞춤(버튼 아래 = 포스터 아래). 그 아래는 범례 → 이름 → 포스터(최대 560px) → 소개 → 사실 → 버튼 순으로 쌓임. 증명사진 칸 = 포스터의 3×4 모듈(정확히 3:4), 사진이 없으면 `primary-100` 바탕에 `primary-300` 실루엣.
- 영어 이름 옆에 `lang="ko"` 한글 이름, 한국어 이름 옆에 `lang="en"` 영문 이름(두 언어의 구조를 같게).

- 도형 컨테이너는 모두 `overflow-hidden`. flex/grid 속 글자에는 `min-w-0`, 이메일·URL은 `wrap-anywhere`.

## 페이지 구성

- **홈**: 히어로(포스터) · 프로젝트(대표 1 + 카드 2, "전체 보기" → 목록) · 대외활동 | 수상(각 3개, 넘치면 "더 보기 (N)" `<details>`) · 학회(THE LAB 카드 + 모듈 열, 행사 3개) · 개발 역량(분류마다 **항목 수만큼** 도형) · 학력 | 연락처(이메일·GitHub·Instagram·Discord 패널, 이메일·Discord 복사 버튼) · 플린스 + 푸터.
- **프로젝트 상세** `/[locale]/projects/[slug]/`: 커버 + 배지(배포 중·대표·형태·관련 수상) · H1 · 한 줄 소개 · 링크 버튼 · 사실 표(기간·팀/역할·진행 상태·배포) → sticky 목차 + 요약 · 내가 한 일 · 화면 · 핵심 기능(행) · 기술 스택(분류 도형) · 결과(수상으로 뒷받침되는 결과는 메달 + 링크) · 문제와 해결(■—● 연결선) · 구조 · 배운 점 · 관련 항목 카드 → 이전/다음(미니 커버). 데이터가 있는 섹션만 목차에 나옵니다.
- **프로젝트 목록** `/[locale]/projects/`: 64px 표식 + H1 + 개수 · (6개 이상이면) 종류 필터 · 최신순 행.

## 구현 시 지켜야 할 동작

1. **날짜**: `formatYm("2025-03" | "2025-03-14") → "2025.03"`, 기간은 `2025.03 – 2025.06`(en dash). 끝이 없으면 `현재`/`Present`, 재학 중인 학력은 `재학 중`/`Enrolled`. 두 언어 같은 형식, 어디서나 최신순.
2. **홈 개수 제한**: 프로젝트 = 대표(없으면 최신) + 2 · 활동/수상/행사 = 3 + 더 보기 · 나머지는 전부. 내용이 없는 섹션은 렌더링하지 않고 내비에서도 뺍니다. 프로젝트의 "전체 보기"는 항상 표시(목록 페이지에는 상태 열이 더 있음).
3. **관계**: DOM id = 내용 id. 관계는 무방향이고 양쪽 모두에 링크가 보여야 합니다(THE LAB 카드에도). 프로젝트 → 상세 페이지, 활동·수상·행사 → 홈의 `#id`(다른 페이지에서는 `/{locale}/#id`). 접힌 `<details>` 안을 가리키면 열어 줍니다(OpenOnHash).
4. **스크롤스파이**: 기준선 = 화면 높이의 35%. 기준선 위의 마지막 섹션과 같은 높이에 있는 섹션들(나란한 행)이 함께 `data-current="true"`. `aria-current="location"`은 정확히 하나: 클릭한 링크가 그 행에 있으면 그것, 아니면 행의 첫 섹션, 페이지 맨 아래에서는 마지막 섹션. 클릭 직후에는 `scrollend`(또는 900ms)까지 스크롤 갱신을 무시합니다. 상세 페이지의 목차도 같은 방식(`aria-current="location"` 하나).
5. **상태 속성은 값으로**: `data-current="true"`, `data-inview="true"`, `data-done="true"`처럼 값을 넣고 `data-[current=true]:` 식으로 선택합니다(빈 속성은 렌더러에 따라 사라질 수 있음).
6. **복사 버튼**: 28px 버튼 + `after:-inset-2`로 44px 터치 영역. "복사" → "복사됨"(`live` 색) / "복사 실패"를 1.6초, 결과는 `role="status"` 하나로 알림. 접근 이름은 "이메일 주소 복사"처럼 대상 포함.
7. **스키마 추가**(선택 필드, 추가할 때는 `src/content/schema.ts` · `docs/prompts/project-fact-sheet.md` JSON 템플릿 · CLAUDE.md 표 · `add-content` 스킬을 함께 고침): `Project.cover?: { motif }`, `Profile.roles?: { kind: WorkKind; label: Localized }[]`(최대 4, 없으면 범례 자리에 headline 글자만). THE LAB 칩은 행사 유형에서 **파생**되므로 필드가 필요 없습니다.
8. **접근성**: 건너뛰기 링크 · 랜드마크(header, nav×2 같은 이름 — 브레이크포인트마다 하나만 보임, main, footer) · 페이지당 H1 하나 · 장식 도형은 모두 `aria-hidden="true"` · 사진은 `<img alt>`(자리표시는 aria-hidden, 시안에서만 `role="img"`) · 외부 링크 "(새 탭)" · 포커스 링 2px 보라(잉크 위에서는 `outline-primary-300`) · stretched link 카드는 카드 전체에 포커스 링(`has-[[data-stretch]:focus-visible]:outline-2`).
9. **사실만**: 시안의 홍길동 내용은 가짜 예시입니다. 상세 시안은 알려진 사실(제목·소개·형태·기간·배포 중·기술·관련 수상/활동)만 쓰고 나머지는 `[요약 — 팩트시트]` 같은 괄호 자리표시입니다.

## 시안 다시 만들기

`mockup/`은 작업 폴더 구조 그대로입니다(`sys/` = 생성기·스크립트, `proto/` = 테마와 출력).

1. 글꼴: `pretendard` npm 패키지의 `PretendardVariable.woff2`를 `mockup/design/fonts/`에 둡니다(커밋하지 않음).
2. `python3 mockup/sys/gen.py proto` → `mockup/proto/sys-{home,detail,list}-{ko,en}/index.html`
3. `cd mockup/proto && npx @tailwindcss/cli@4 -i sys-input.css -o sys.css` (캔버스용은 `--minify` 후 `python3 ../sys/flatten.py <입력> <출력>` — 캔버스 런타임의 CSS가 Tailwind 레이어를 이기지 못하게 `@layer`를 풉니다)
4. `node mockup/sys/shoot.mjs` (스크린샷 + 높이·글자 크기·날짜·도형 겹침 감사), `node mockup/sys/verify.mjs` (위 검증표 전체)
5. 캔버스: CSS를 캔버스 자산으로 올리고 `python3 mockup/sys/gen.py dc /_blob/<id> mockup/design2` → `canvas.json`과 아트보드 12개를 게시.
