# 디자인 시안 — "움직이는 포스터 (Moving Poster)"

구현의 기준이 되는 디자인입니다. 시안 캔버스: <https://claude.ai/artifact/95ysTmLFNbQUmphosPmcRx> (홈·상세·목록 × 한국어/English × 1440/390, 12개 아트보드, 모두 인터랙티브).
시안은 [`mockup/sys/gen.py`](mockup/sys/gen.py) 하나에서 생성됩니다. 같은 마크업이 ① Tailwind로 컴파일한 정적 페이지 6개(`mockup/proto/sys-*`)와 ② 캔버스 아트보드 12개가 됩니다. 디자인을 바꿀 때는 생성기를 고치고, 다시 렌더링·검증한 뒤 캔버스에 올립니다(맨 아래 "시안 다시 만들기").

시안의 클래스 문자열이 그대로 실제 컴포넌트의 클래스가 됩니다. 시안과 사이트가 같은 Tailwind 토큰과 유틸리티를 씁니다.

## 콘셉트

흰 바탕 위의 평면 바우하우스 포스터. 모든 것이 정사각형 모듈 위에 놓입니다.

- **도형이 구조다.** 도형은 격자 칸(포스터 모듈, 커버 패널, 모듈 열, 썸네일)을 차지합니다. 텍스트는 절대 도형 위에 올리지 않습니다.
- **도형이 뜻을 가진다.** 전역 **도형 범례(Shape Key)** 하나가 일의 종류를 표시하고, 섹션마다 **종류 표식(kind mark)** 이 있습니다. 프로젝트 커버는 그 프로젝트가 하는 일(타이머·QR·챗봇…)에서, 썸네일은 활동 유형에서, 기술 도형은 기술 분류에서 나옵니다.
- **움직임은 릴레이다.** 한 섹션 안에서는 한 번에 도형 하나만, 1.2–2.4초 동안 한 걸음 움직이고 멈춥니다. 각 도형은 24초에 한 번 움직입니다. 몇 초마다 한 조각씩 바뀌는 포스터처럼 보입니다.
- **날짜는 그냥 글자.** 항상 `yyyy.mm`, `tabular-nums`. 날짜로 위치·크기·도형을 만들지 않습니다.

모서리는 전부 직각. 색은 잉크·보라·보라 틴트·흰색뿐입니다. 그라데이션·그림자·블러·이모지 없음.

- 줄간격·자간 토큰: `leading-copy` 1.7 (관계 줄·소개 문구) · `leading-prose` 1.75 (한국어 문단) · `leading-read` 1.8 (상세 요약) · `leading-display` 1.1 · `tracking-display` −0.03em.
- 유틸리티: `tri`, `tri-corner`(clip-path 삼각형), `anim-delay-N`(N×100ms, 포스터 등장 순서), `anim-offset-N`(루프를 N초 앞당겨 시작), `play-gate`, `shell`(최대 1240px, 좌우 16/24/40px).
- 기본 규칙(`@layer base`): `h1,h2,h3 { text-wrap: balance }` · `a, button, summary { touch-action: manipulation }`(더블탭 확대 지연 없음) · `-webkit-tap-highlight-color: transparent`(대신 `:focus-visible` 링과 `active:` 테두리) · `img`는 로딩 중 `surface` 바탕.
- 임의값(`[...]`)은 도형 안의 % 기하, grid 템플릿, `[--scan-to:…]`/`[--play:…]`, `forced-colors:bg-[CanvasText]`에만 씁니다. 나머지는 Tailwind 기본값(`max-w-136`, `min-h-100`, `aspect-16/10`, `aspect-8/7`, `inset-0.75` …)이나 위 토큰으로.

## 도형 어휘

모든 도형은 Tailwind만으로 만듭니다(SVG 없음). 도형은 `relative overflow-hidden` 모듈 안에 % 단위로 배치해서 80px~560px 어디서든 같은 구성이 됩니다.

| 도형      | 레시피                                                                                           |
| --------- | ------------------------------------------------------------------------------------------------ |
| 사각형    | `div` + `bg-*`                                                                                   |
| 원        | `rounded-full`                                                                                   |
| 사분원    | `rounded-tl-full` (tr/br/bl)                                                                     |
| 반원·아치 | `aspect-[2/1] rounded-t-full` (매달린 반원 `rounded-b-full`)                                     |
| 삼각형    | `tri` + 한 변 기준 크기와 `aspect-8/7`(정삼각형에 가까운 비율 고정) · 모서리 삼각형 `tri-corner` |
| 마름모    | 사각형 + `rotate-45`                                                                             |
| 말풍선    | `rounded-full rounded-bl-none`                                                                   |
| 반반 원   | `rounded-full overflow-hidden` + 왼쪽 절반 `bg-ink`                                              |
| 메달      | 원 + 가운데 흰 원                                                                                |

한 구성 안의 비율은 대략 잉크 25% · 보라 30% · 틴트와 흰색 45%. 이웃한 모듈은 배경색이 겹치지 않게 합니다.

### 섹션 표식과 관계 링크 표식

- **48px 섹션 표식**(h2 옆, 정지): 프로젝트 = 잉크 칸 + 보라 원 + 틴트 사분원 · 대외활동 = 틴트 칸 + 잉크 삼각형 · 수상 = 잉크 칸 + 메달 · 학회 = 잉크/보라 두 사각형 · 개발 역량 = 사분원 4개 · 학력 = 아치 건물 · 연락처 = 겹친 두 원. 목록 페이지는 64px.
- **14px 관계 표식**: 모든 관계 링크는 대상 컬렉션의 표식으로 시작합니다(프로젝트 = 잉크 칸 속 원, 대외활동 = 잉크 삼각형, 수상 = `award` 메달, 학회 = 두 사각형, 학회 행사 = 그 행사의 범례 기호). 표식이 항목을 구분하므로 링크 사이에 `·`를 넣지 않습니다(줄바꿈 때 점이 줄 머리에 남는 문제 방지).

### 그 밖의 도형 매핑 (`src/components/shapes/maps.ts`, 클래스는 리터럴로만)

- **활동 썸네일**(56/64px, 흰 칸): competition = 삼각형 + 잉크 점 · community = 사각형 + 원 + 사분원 · program/bootcamp = 엇갈린 두 사각형 · internship = 잉크 막대 위 보라 사각형 · volunteer = 원 위 아치 · conference = 잉크 반원 + 보라 막대 · other = 잉크 마름모.

## 프로젝트 화면 (스크린샷)

프로젝트의 대표 이미지는 **실제 작동 화면**입니다. 도형은 그 화면을 받치는 틀이고, 화면을 대신하지 않습니다.

- **캡처 비율은 셋뿐이고 자르지 않습니다**: 웹 `aspect-16/10`(1440×900 등) · 휴대폰 `aspect-6/13`(≈ 9:19.5, 1170×2532 등) · 사진 `aspect-4/3`. 칸이 비율을 고정하고 이미지는 같은 비율로 준비합니다. 예외는 행사 사진과 사진만 있는 프로젝트의 카드(칸에 맞춰 `object-cover`, 태그에 비율 없음).
- **도형 모듈은 캡처 옆 칸에만**. 글자와 캡처 위에는 올리지 않습니다. 캡처에 닿는 모듈은 흰색·`primary-100`을 쓰지 않습니다(밝은 UI 캡처와 경계가 사라짐).
- **원본 크기로 보기**: 상세 페이지의 캡처(히어로 포스터의 웹·휴대폰 칸, 갤러리 전부)는 실제 사이트에서 `<a href="{원본 파일}" target="_blank" rel="noopener noreferrer">`로 감쌉니다. 접근 이름 = `alt` + "(원본 크기로 보기, 새 탭)". 오른쪽 아래 32px 흰 칩 안의 잉크 사각형 테두리가 그 표시입니다. 줄인 캡처 속 UI 글자는 6–7px까지 작아지므로, 데스크톱에서도 원본을 열 수 있어야 합니다(정적 내보내기라 JS 없는 링크). 홈 카드와 목록 행의 캡처는 카드 전체 링크(상세 페이지)에 속하므로 따로 링크하지 않습니다.
- **자리표시(시안 전용)**: `primary-100` 바탕 + `ring-1 ring-inset ring-line` + 가운데 일반 이미지 기호(해 + 산, 증명사진 실루엣과 같은 어휘) + 왼쪽 위 흰 태그("웹 화면 16:10", 좁은 칸은 "휴대폰 9:19.5"). 칸이 104px보다 좁으면 태그는 숨깁니다(`@container` + `@max-[6.5rem]:hidden`). 앱을 그린 가짜 화면은 만들지 않습니다. 실제 사이트에는 태그가 없고, 캡처가 없으면 **모티프 커버**가 같은 자리에 들어갑니다.
- **이름은 하나로**: 태그·캡션·개수 모두 "웹 화면 / 휴대폰 화면 / 사진"(짧게 "웹 / 휴대폰 / 사진").

## 움직임

1. **모든** 애니메이션과 transform 전환은 `motion-safe:` 뒤에(등장 `pop`은 `motion-on:`). 색·테두리 전환만 예외. `motion-on:` = 테마의 커스텀 변형: `prefers-reduced-motion: no-preference` **이고** 멈춤 버튼으로 멈추지 않았을 때(`&:not([data-motion="off"] *)`). 루프는 `--play`로 멈추지만 등장은 일시정지로 멈출 수 없어서 따로 둡니다.
2. **움직임 줄이기 = 설계된 정지 구성.** 모든 키프레임의 0% 자세가 곧 정지 화면이고, 스크린샷도 그 상태입니다. 이때 멈춤 버튼은 숨깁니다.
3. 헤더의 멈춤 버튼(라벨은 늘 "움직임 멈추기", `aria-pressed="true"` = 멈춤, `localStorage` 키 `motion`)이 루트에 `data-motion="off"`를 걸면 `--play: paused`가 상속되어 모든 루프가 멈춥니다(WCAG 2.2.2). 화면 밖 루프는 `play-gate` 컨테이너 안에 있고, IntersectionObserver 하나가 `data-inview="true"`를 걸어 줄 때만 돕니다.
4. **릴레이 규칙**: 한 섹션의 루프는 24초 주기를 나눠 씁니다. 히어로 포스터는 3·9·15·21초에 한 걸음씩(사분원 90° 회전 → 사각형이 마름모로 → 아치 속 해가 떠오름 → 잉크 막대의 반원이 미끄러짐). 동시에 둘이 움직이지 않습니다(검증 스크립트가 100ms 간격으로 확인).
5. 연속으로 도는 루프는 없습니다. 루프 주기는 24·48·96초뿐.
6. 키프레임은 `transform`/`opacity`만. hover는 Tailwind의 `translate`/`rotate`/`scale` 속성을 쓰므로 루프와 겹치지 않습니다. 같은 요소·같은 속성에 hover와 루프를 같이 두지 않습니다.

- 오프셋은 "로드 순간의 자세 = 정지 자세"가 되도록, 그리고 섹션이 보인 뒤 몇 초 안에 첫 걸음이 나오도록 골랐습니다(연락처 6초, 플린스 3·9초, THE LAB 2초). 새 루프를 넣을 때도 이 조건을 지킵니다.
- **등장은 한 번, 한 곳**: 히어로 포스터 모듈이 사진에서 가까운 순서로 `motion-on:animate-pop`(0.8초, 0→1배, 0–400ms 지연). 저장된 멈춤 상태는 `<head>`의 인라인 스크립트가 첫 그림 전에 `<html data-motion="off">`로 걸어서 등장도 나오지 않습니다. 상세 히어로도 모듈만 `pop`(캡처 칸은 그대로). 글자 떠오르기·스크롤 등장·종류 표식 등장은 없앴습니다(frontend-design 리뷰: 흩어진 등장 효과는 템플릿 티가 나고, 도형 릴레이와 주의를 다툼).
- **hover/focus는 누를 수 있는 것에만** (500–700ms, `ease-snap`, transform은 motion-safe): 로고 도형 · 히어로 포스터 도형이 한 칸씩 비켜남("프로젝트 보기" 버튼과 짝) · 프로젝트 카드 = `hover:border-ink` + 모티프 조각 한 걸음 · 내비 현재 막대 `scale-x` · 버튼 원은 작아지고 사각형은 마름모로 · 터치에서는 `active:border-ink`/`active:bg-primary-50`. 누를 수 없는 썸네일·행사 그림·학력 아치에는 hover 움직임이 없습니다. 예외 하나: 학회 행사 타일에 올리면 THE LAB의 같은 종류 모듈에 흰 링(움직임 없는 관계 표시, 움직임 줄이기에서도 보임).

## 레이아웃과 반응형

- 앵커 오프셋은 루트 하나에서: `<html class="scroll-smooth scroll-pt-32 md:scroll-pt-24 lg:scroll-pt-20 tiny:scroll-pt-0 …">`. 섹션·행에는 `scroll-mt`를 두지 않습니다(겹쳐 더해짐). 덕분에 건너뛰기 링크, "맨 위로", Shift+Tab 포커스도 헤더 아래에 떨어집니다(WCAG 2.4.11).
- 섹션 래퍼: `border-t border-line`, 안쪽 `shell py-8 sm:py-10 lg:py-12`. 학회만 `bg-surface`, 위 테두리 없음.
- **헤더**(sticky): 640 미만 = 44px 줄 + 4×2 격자(36px 행) = 118px, 8개 섹션이 모두 한눈에. 768–1023 = 44px + 한 줄 8칸(44px) = 89px. 1024 이상 = 64px 한 줄, 현재 섹션 아래 4px 보라 막대. 세로 500px 이하 화면은 가로 스크롤 띠. 하단 hairline은 `after:`로 그려서 높이에 포함.
- **히어로**: 1024 이상 12열 — 왼쪽 6열 = 범례 + 이름, 오른쪽 6열 = 5×5 포스터(최대 560px). 1280 이상에서 소개·사실·버튼을 포스터 아래 끝에 맞춥니다(버튼 아래 = 포스터 아래). 1024–1279는 이름 72px·소개 18px로 줄이고 포스터를 글 열의 세로 가운데에 둡니다. 그 아래는 범례 → 이름 → 포스터(최대 560px) → 소개 → 사실 → 버튼 순으로 쌓임. 증명사진 칸 = 포스터의 3×4 모듈(정확히 3:4), 사진이 없으면 `primary-100` 바탕에 `primary-300` 실루엣.
- 영어 이름 옆에 `lang="ko"` 한글 이름, 한국어 이름 옆에 `lang="en"` 영문 이름(두 언어의 구조를 같게).

## 구현 시 지켜야 할 동작

1. **날짜**: `formatYm("2025-03" | "2025-03-14") → "2025.03"`, 기간은 `2025.03 – 2025.06`(en dash). 끝이 없으면 `현재`/`Present`, 재학 중인 학력은 `재학 중`/`Enrolled`. 두 언어 같은 형식, 어디서나 최신순.
2. **홈 개수 제한**: 프로젝트 = 대표(없으면 최신) + 2 · 활동/수상/행사 = 3 + 더 보기 · 나머지는 전부. 내용이 없는 섹션은 렌더링하지 않고 내비에서도 뺍니다. 프로젝트의 "전체 보기"는 항상 표시(목록 페이지에는 상태 열이 더 있음).
3. **관계**: DOM id = 내용 id. 관계는 무방향이고 양쪽 모두에 링크가 보여야 합니다. 관계는 내용에 적힌 것만 — 같은 해커톤처럼 보여도 추측해서 잇지 않습니다(시안은 스터디 타이머 ↔ OO 해커톤 대상/참가 두 개뿐). 프로젝트 → 상세 페이지, 활동·수상·행사 → 홈의 `#id`(다른 페이지에서는 `/{locale}/#id`). 접힌 `<details>` 안을 가리키면 열어 줍니다(OpenOnHash).
4. **스크롤스파이**: 기준선 = 헤더 아래 끝 + 24px(앵커가 떨어지는 자리라서, 짧은 섹션도 클릭하면 현재가 됨). 기준선 위의 마지막 섹션과 같은 높이에 있는 섹션들(나란한 행)이 함께 `data-current="true"`. `aria-current="location"`은 정확히 하나: 클릭한 링크가 그 행에 있으면 그것(맨 아래까지 올라오지 못하는 섹션도 클릭했다면 유지), 아니면 행의 첫 섹션, 페이지 맨 아래에서는 마지막 섹션. 클릭 직후에는 `scrollend`(또는 900ms)까지 스크롤 갱신을 무시합니다. 상세 페이지의 목차도 같은 방식(`aria-current="location"` 하나).
5. **상태 속성은 값으로**: `data-current="true"`, `data-inview="true"`, `data-done="true"`처럼 값을 넣고 `data-[current=true]:` 식으로 선택합니다(빈 속성은 렌더러에 따라 사라질 수 있음).
6. **복사 버튼**: 28px 버튼 + `after:-inset-2`로 44px 터치 영역. "복사" → "복사됨"(`live` 색, 1.6초), 결과는 `role="status"` 하나로 알림. 접근 이름은 "이메일 주소 복사"처럼 대상 포함. **클립보드가 막히면**(권한 거부·비보안 컨텍스트) "복사 실패"(`award` 색, 4초) + 상태 알림 "복사하지 못했어요. 선택된 글자를 직접 복사해 주세요." + 값 글자(`data-copy-value`)를 선택해 둡니다. 연락처 칸은 칸 전체가 링크(`after:absolute after:inset-0`), 복사 버튼은 `z-10`으로 그 위.
7. **스키마 추가**(선택 필드, 추가할 때는 `src/content/schema.ts` · `docs/prompts/project-fact-sheet.md` JSON 템플릿 · CLAUDE.md 표 · `add-content` 스킬을 함께 고침): `Project.cover?: { motif }`, `Profile.roles?: { kind: WorkKind; label: Localized }[]`(최대 4, 없으면 범례 자리에 headline 글자만). THE LAB 칩은 행사 유형에서 **파생**되므로 필드가 필요 없습니다.
   - **`Project.media?`** (새 선택 필드): `{ kind: "web" | "mobile" | "photo"; src: string; width: number; height: number; alt: Localized; caption?: Localized }[]`. 순서 = 보여 줄 순서. 첫 `web` = 카드·목록·포스터의 큰 캡처, 첫 `mobile` = 포스터의 휴대폰 칸, 전부 = 상세 갤러리. 파일은 `public/projects/<id>/`. 검증기(`validate:content`)가 `width/height` 비율이 종류의 비율(16:10 · 6:13 · 4:3, ±1%)과 맞는지, 파일이 있는지 확인합니다. `alt`·`caption`은 팩트시트에서(화면이 무엇을 보여 주는지), 지어내지 않습니다.
   - **`SocietyEvent.photo?`**: `{ src, width, height, alt: Localized }` 하나. 이 사진만 칸에 맞춰 잘립니다.
   - `docs/prompts/project-fact-sheet.md`에 "화면 캡처" 항목을 추가합니다(어느 화면인지, 웹/휴대폰, 파일 경로, 한 줄 설명). 캡처가 없으면 필드를 비워 두고 모티프 커버가 그 자리를 씁니다.
8. **터치**: hover가 없는 기기를 위해 누를 수 있는 것마다 `active:` 상태(카드 `active:border-ink`, 버튼·언어 `active:bg-primary-100`, 채운 버튼 `active:bg-primary`, 내비 칸·이전/다음 `active:bg-primary-50`, 글자 링크 `active:underline`). 헤더의 32px 멈춤 버튼과 언어 링크는 `after:` 의사 요소로 터치 영역을 44px 가까이 넓힙니다(상자 크기는 그대로).
9. **접근성**: 고대비(forced-colors) 모드에서도 현재 위치가 보이게 — 내비 막대·목차 칸은 `forced-colors:bg-[CanvasText]`, 현재 언어는 밑줄, 채운 버튼은 `border-transparent`로 테두리 유지 · 내비 포커스 링은 `focus-visible:z-20 focus-visible:-outline-offset-2`(이웃 칸·스크롤 띠에 잘리지 않게) · 건너뛰기 링크 · 랜드마크(header, nav×2 같은 이름 — 브레이크포인트마다 하나만 보임, main, footer) · 페이지당 H1 하나 · 장식 도형은 모두 `aria-hidden="true"` · 사진은 `<img alt>`(자리표시는 aria-hidden, 시안에서만 `role="img"`) · 외부 링크 "(새 탭)" · 포커스 링 2px 보라(잉크 위에서는 `outline-primary-300`) · stretched link 카드는 카드 전체에 포커스 링(`has-[[data-stretch]:focus-visible]:outline-2`).
10. **사실만**: 시안의 홍길동 내용은 가짜 예시입니다. 상세 시안은 알려진 사실(제목·소개·형태·기간·배포 중·기술·관련 수상/활동)만 쓰고 나머지는 `[요약 — 팩트시트]` 같은 괄호 자리표시입니다.
11. **이미지 포팅**: 정적 내보내기라 Next 기본 이미지 로더를 쓸 수 없습니다 — `<img>`(또는 `images.unoptimized`)에 항상 `width`/`height`(CLS 0), 칸의 `aspect-*`와 같은 비율, `loading="lazy" decoding="async"`, 상세 히어로의 큰 캡처 하나만 `fetchpriority="high"`(lazy 아님). 형식은 WebP/AVIF(원본 PNG 보관은 저장소 밖), 웹 캡처 긴 변 1600px·휴대폰 1200px 정도. GIF 금지 — 움직이는 화면이 필요하면 `<video muted loop playsinline poster>`를 주인에게 먼저 묻고, 움직임 멈춤·`prefers-reduced-motion`에서는 재생하지 않습니다. 캡처 칸에는 `bg-surface`가 로딩 중 바탕.
12. **머리 스크립트**: 움직임 멈춤 상태는 첫 그림 전에 적용해야 깜빡이지 않습니다 — `<head>`의 작은 인라인 스크립트가 `localStorage.motion`을 읽어 `<html data-motion>`을 겁니다(`next/script` `beforeInteractive` 또는 `layout.tsx`의 `<script dangerouslySetInnerHTML>`, `<html suppressHydrationWarning>`). `<meta name="theme-color" content="#ffffff">`, 글꼴은 Pretendard dynamic subset.

## 디자인 리뷰 기록 (2026.10, 설치한 디자인 스킬 3개)

`web-design-guidelines`(Vercel 규칙 전체), `ui-ux-pro-max`(우선순위 1–9 + 검색 DB), `frontend-design`(디자인 리드 관점)으로 각각 검토하고, 지적마다 다른 검토자가 반박을 시도해서 살아남은 것만 고쳤습니다.

- **문제였던 것**: 프로젝트 대표 이미지가 생성된 도형뿐이라 실제 작동 화면을 넣을 자리가 없었음 → 위 "프로젝트 화면" 체계(미니 포스터 · 캡처 유닛 · 갤러리 · 원본 보기).
- **같이 고친 것**: 휴대폰·사진만 있는 프로젝트도 커버에 캡처 표시 · 화면이 없거나 1장이면 "화면" 섹션·목차 숨김 · 갤러리 휴대폰 크기 키움(약 200 → 300px) · 접기가 휴대폰 짝을 나누지 않음 · 보조 카드 가로형(대표 캡처가 늘 가장 큼, 홈 1440 −300px) · 터치 `active:` 상태 · 헤더 터치 영역 · 멈춤이 등장 애니메이션도 멈춤 + 첫 그림 전에 적용 · 복사 실패 처리 · 이름 통일("웹 화면") · 미니 시계 모티프 정리.
- **뺀 것**: 글자 떠오르기·스크롤 등장·종류 표식 등장, 누를 수 없는 것의 hover 움직임, `dt` 앞 점, 상세 h2마다 다른 장식 도형, H1 위 배지, "대표 프로젝트" 라벨, 가운뎃점 메타 문자열, 링크 글자 뒤 화살표.
- **주인 요청이라 남긴 것**: 도형과 릴레이 움직임 전체(연락처 모듈 열, 학력 아치, 개발 역량 루프, THE LAB 링). frontend-design은 "장식은 덜어 내라"고 했지만 기하 도형과 움직임은 주인이 고른 방향입니다.
- **반박되어 버린 지적**(예): 이미지 로딩 계약(시안에 이미지가 없음 — 대신 "이미지 포팅" 항목에 적음), 목록 링크 터치 크기(24px로 WCAG 2.5.8 충족), 행사 사진 비율 고정(잘라 채우기가 의도), 삼각형 화살표(이 디자인의 도형 어휘).

## 시안 다시 만들기

`mockup/`은 작업 폴더 구조 그대로입니다(`sys/` = 생성기·스크립트, `proto/` = 테마와 출력).

1. 글꼴: `pretendard` npm 패키지의 `PretendardVariable.woff2`를 `mockup/design/fonts/`에 둡니다(커밋하지 않음).
2. `python3 mockup/sys/gen.py proto` → `mockup/proto/sys-{home,detail,list}-{ko,en}/index.html`
3. `cd mockup/proto && npx @tailwindcss/cli@4 -i sys-input.css -o sys.css` (캔버스용은 `--minify` 후 `python3 ../sys/flatten.py <입력> <출력>` — 캔버스 런타임의 CSS가 Tailwind 레이어를 이기지 못하게 `@layer`를 풉니다)
4. `node mockup/sys/shoot.mjs` (스크린샷 + 높이·글자 크기·날짜·도형 겹침 감사), `node mockup/sys/verify.mjs` (위 검증표 전체), `python3 mockup/sys/scen.py && (cd mockup/proto && npx @tailwindcss/cli@4 -i _scen-input.css -o _scen.css) && node mockup/sys/scen.mjs` (화면 경계 사례)
5. 캔버스: CSS를 캔버스 자산으로 올리고 `python3 mockup/sys/gen.py dc /_blob/<id> mockup/design2` → `canvas.json`과 아트보드 12개를 게시.
